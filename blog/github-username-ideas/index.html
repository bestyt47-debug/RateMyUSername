A GitHub username is a rare case where your handle can genuinely affect your career. It's the address of your portfolio, the name on every pull request and the first thing a recruiter sees when they click through from your resume. If it reads clean and professional, you look like someone who takes their craft seriously. If it's a string of numbers or a joke you've outgrown, it can quietly work against you.

That said, GitHub culture also loves personality, so you don't need to be boring. The trick is a name that's easy to type, easy to say in an interview and still feels like you. The rules are strict: letters, numbers and single hyphens only, no underscores, no leading or trailing hyphens. Below are 100 usernames that follow those rules, sorted into five styles. Use one as is or as a base for your own.

How to choose a GitHub username that ages well

Your GitHub name will appear in URLs, docs and job applications, so it's worth getting right.

  • Remember there are no underscores. GitHub usernames allow letters, numbers and single hyphens only, so use hyphens to separate words.
  • Don't start or end with a hyphen. Names can't begin or end with a hyphen, and they can't have two in a row.
  • Go professional first. A name based on your real name or a neutral handle is safer for job hunting than a joke.
  • Match your other developer handles. Consistency across GitHub, X, LinkedIn and your site makes you easy to find.
  • Think about your GitHub Pages URL. Your username becomes part of your personal site address, so shorter looks better.

FAQ

What are the GitHub username rules?
Usernames can contain letters and numbers plus single hyphens. They can't begin or end with a hyphen, can't contain two hyphens in a row, and can be up to 39 characters. Underscores aren't allowed.
Can I change my GitHub username?
Yes, from Settings under Account. It's free and unlimited, but the change has side effects. Your profile URL changes, and links that used the old name may no longer work, so update your portfolio and resume.
What happens to my repositories if I change my username?
Repository URLs on the web generally redirect to your new name, but profile links do not, and your old name becomes available to others. Update remotes in your local clones to be safe.
Should I use my real name on GitHub?
It depends. For job hunting, a name based on your real one looks professional. If you'd rather stay separate, choose a clean handle that hints at your specialty.
Does my GitHub username affect my personal site?
If you use GitHub Pages, your username forms the default URL, like username.github.io. A shorter, cleaner name makes that address easier to share.
